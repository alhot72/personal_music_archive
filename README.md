# Cosmic Music — космический музыкальный архив

Тёмный «космический» веб-архив музыкальных черновиков, вдохновлённых эпохой Space-музыки (Space, Zodiac, Jean-Michel Jarre). Автор оцифровал старые записи с катушечного магнитофона «Сатурн-202-3», сделанные в 90-х на детском синтезаторе Casio MA-100, и восстановил их с помощью ИИ.

Проект сделан на чистом PHP (без фреймворков) и нативном JavaScript — показывает весь цикл от бэкенда и хранения до дизайна и деплоя.

---

## Возможности

- **Космический дизайн**: баннер с галактикой, мерцающие звёзды на canvas, туманности, адаптивная вёрстка.
- **5 разделов**: Главная (история), Музыка (черновики с каверами), Песни, Плеер, Админка.
- **Двуязычность** RU/EN: выбор языка сохраняется в сессии, все тексты через функцию `t()`.
- **Кастомный плеер в стиле WinAmp** (ностальгия по 90-м): общий плейлист, перемотка, громкость, авто-переход к следующему треку.
- **Отзывы и рейтинг (1–10)**: под каждым кавером/песней — форма с интерактивными звёздами; отзывы сохраняются в `reviews.json`.
- **Админ-панель**: плитка композиций, к которым есть отзывы, с кнопкой «Развернуть» (слушатели, средний рейтинг); статистика посещений.
- **Статистика посещений** по страницам (анонимизированный IP) в `stats.json`.

## Технологии

- PHP 8.1+ (строгая типизация, без фреймворков)
- Нативный JavaScript (ES6), CSS3 с переменными
- HTML5 `<audio>` / Web Audio для плеера
- Хранение данных в JSON-файлах (отзывы, статистика) — без БД
- PHP-встроенный сервер или любой хостинг с PHP

## Структура

```
├── index.php        Главная (история + фото)
├── music.php        Черновики (orig) с выпадающими каверами
├── songs.php        Песни с вокалом
├── playlist.php     Единый WinAmp-плеер
├── admin.php        Админка: плитки композиций + статистика
├── config.php       Пути, пароль (из env), версия ресурсов
├── helpers.php      Логика: сканирование, отзывы, статистика, шапка/подвал
├── lang.php         Словарь локализации RU/EN + функция t()
├── style.css        Космическая тема
├── script.js        Звёзды, плеер WinAmp, рейтинг, плитки админки
├── reviews.json     Отзывы (создаётся на сервере)
├── stats.json       Статистика посещений (создаётся на сервере)
```

## Установка и запуск

### Требования
- PHP 8.1+
- Веб-сервер с PHP (Apache/nginx) **или** встроенный PHP-сервер

### Быстрый старт со встроенным сервером

```bash
php -S localhost:8000
```

Откройте `http://localhost:8000`

### Запуск на хостинге

1. Загрузите файлы проекта в корень сайта.
2. Создайте папки `music/orig`, `music/covers`, `music/songs` и положите MP3 (имена вида `My_music-01.mp3` для черновиков).
3. Задайте пароль администратора через переменную окружения `ADMIN_PASSWORD` (см. ниже).
4. Убедитесь, что `reviews.json` и `stats.json` доступны для записи.

## Пароль администратора

Для безопасности пароль **не захардкожен**. Он читается из переменной окружения `ADMIN_PASSWORD`.

- В среде Apache через `.htaccess`:
  ```apache
  SetEnv ADMIN_PASSWORD "your-secret-pass"
  ```
- В панели хостинга — задайте переменную окружения, если поддерживается.
- В локальной строке запуска:
  ```bash
  ADMIN_PASSWORD="your-pass" php -S localhost:8000
  ```

Если переменная не задана — вход в админ-панель остаётся закрытым (пароль пустой).

## Соглашения об именах файлов

- **Черновики** (`music/orig`): `My_music-01.mp3`, `My_music-02.mp3` — номер связывает с каверами.
- **Каверы** (`music/covers`): `My_music-01-Deep_Space.mp3` — префикс `My_music-<номер>-`, после него читается название.
- **Песни** (`music/songs`): любые `.mp3`.
